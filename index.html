    How to use the fixer

    The fixer handles two things Ally flags in PowerPoint files: slides with no title, and pictures with no description (alt text). You open a .pptx file, type what's missing, and download a fixed copy to upload to Canvas. Your file never leaves your computer.

    Fix a file, step by step

    1. Open your file. Choose a .pptx file, or drag one onto the box on the start page. If your file ends in .ppt, open it in PowerPoint first and save it as .pptx.
    2. Scroll through the slides. Every slide is on one long page, with its text, a title box and a box for each picture. The list beside the slides jumps to any slide and shows what each one is missing.
    3. Type a title on every slide flagged "missing". See writing slide titles.
    4. Describe each picture flagged "needs alt text", or check "decorative, no description needed" if it's only there for looks. See writing alt text.
    5. Check the document title under "File properties" at the bottom of the slide list. Ally copies it into the PDF and HTML versions students download, so it should name the lecture, not the file.
    6. Download the fixed copy. "Download fixed copy" saves a new file with "(fixed)" added to its name. Your original file isn't changed.
    7. Upload the fixed copy to Canvas and check its Ally score. Ally checks more than this page does, so it may still flag things like text contrast.

    The line under the file name counts what's left, for example "2 slides still need a title". When it says every slide has a title and every picture has alt text, you're done with this page.

    Writing slide titles

    Screen reader users move through a deck by its slide titles, and Ally turns them into headings in the HTML and PDF versions. A good title says what the slide is about.

    • Use a few words that tell this slide apart from the others, like "Gestalt principle: proximity".
    • Don't repeat the same title on every slide. If slides continue a topic, add "(continued)" or a part number.
    • For a slide that's one artwork, the artist and title of the work make a good slide title.

    Why some titles go above the slide

    On slides that are mostly picture, the fixer puts the title just above the slide's edge. It won't show when you present, but screen readers and Ally still find it. In sandbox tests, a title typed on top of a full-slide picture was flagged by Ally for low contrast, and the same title above the slide wasn't. The hint under each title box tells you which kind of slide you're on.

    Writing alt text

    Alt text is what a screen reader says in place of a picture. Write what a student would miss if they couldn't see it. The slide's own text is shown above the boxes so you can see what's already said.

    • Describe what the picture shows and why it's on this slide. One or two sentences is usually enough.
    • Skip "image of" or "picture of". Screen readers already say it's a picture.
    • If the picture contains words that matter, type those words.
    • If the slide text already says everything the picture shows, a short description is fine.
    • For artwork, describe what's visible and leave out the title and artist. Alt text gives a screen reader user what a sighted viewer sees. Put the title and artist in the slide title or slide text instead.

    Decorative pictures

    Check "decorative, no description needed" for pictures that add nothing to the content, like a border, a background flourish or a logo repeated on every slide. Screen readers skip them.

    The same picture on several slides

    When a picture appears more than once, a checkbox under it offers to use your description on the other slides too. It's on by default. It only fills boxes you haven't typed in yourself.

    "PowerPoint guessed this"

    Older versions of PowerPoint wrote alt text automatically, ending in "Description automatically generated". Nobody checked these, so the fixer flags them. Read each one against the picture and rewrite it. Once you remove the "Description automatically generated" line, it counts as checked.

    Pictures used as a slide background

    A background picture can't hold alt text. If it matters to the content, describe it in the slide title or the speaker notes. The fixer tells you when a slide has one.

    Drafting with an AI assistant

    Because the fixer is a web page, an AI assistant in the browser, such as Gemini in Chrome, can draft the titles and alt text for you to review. Unlike PowerPoint's Generate alt text button, you give the assistant a prompt that says what you want. For a deck of artwork, the prompt can follow best practices for describing art.

    1. Open your file in the fixer.
    2. Open the assistant in the same browser window and paste your prompt.
    3. Let it work down the page. When it's done, read every title and description against its picture before you download. The assistant can be confidently wrong, and only a person looking at the picture will catch it.

    The assistant reads the page, including the pictures, and sends it to the company that runs the assistant. The fixer itself never uploads your file, but the assistant does see it. Only use one on a deck you're allowed to share with that service.

    Some assistants can skip the clicking and use tools the fixer offers them. The ChatGPT desktop app does this in its built-in browser, where an arrow in the address bar means it found the tools. With them it can list what still needs work, go to a slide, and fill in title and description boxes. It can't download, open a file or mark a picture decorative. Those stay with you. ChatGPT's tools are turned off in college Edu workspaces, so they need a Plus or other personal plan.

    Example prompt for art slides

    Show the prompt 
    This web app is designed to fix PowerPoint slides for accessibility. Every slide is on this one page, one section after another. Work down the page from Slide 1 to the last slide. For each slide the list on the left marks "Needs title" or "Needs alt text", fill in the slide title box and the description box for each picture, then scroll down to the next slide. Keep going until no slide in the list says "Needs". Don't download the file.

These are art lecture slides. Write each picture description by these rules:

1. Open with the medium and form: "Oil painting of", "Bronze sculpture of", "Charcoal drawing of", "Collage of". Use "Photograph of" only when the artwork itself is a photograph, not for a photo of a painting or an installation. Never open with "Image of", "Picture of" or "Installation view of".
2. Put the most important thing in the picture first, then supporting detail: subject, action, setting.
3. Include color, light and composition when they carry meaning. In artwork they usually do.
4. Write one sentence of 15 to 30 words.
5. Type out any words visible inside the artwork exactly as they appear, in quotation marks.
6. Describe what's there, don't interpret it. Write "clenched jaw, gaze turned away", not "looks angry". The exception is when a little interpretation is needed to make sense of what's shown.
7. Don't repeat what the slide text already says.
8. Never name a title, artist, date, art movement or museum, even if you recognize the work. If you recognize it, use that knowledge only to describe more accurately, for example "gold leaf" instead of "yellow patterning". Don't write anything that assumes the reader already knows the work.
9. If a description is already in the box and it ends with "Description automatically generated", replace it. It can be considered unreliable.

For each slide title, write a few plain words that say what the slide is about, so someone using a screen reader can tell the slides apart. Don't number them, and don't use the artist's name or the artwork's title.

    The prompt keeps artist names out of the titles too, because AI assistants misidentify artwork. Once you've checked the drafts, add the title and artist to the slide titles yourself where they belong.

    Saved work

    What you type is saved in this browser as you go. To pick up later, come back to the fixer and open the same file again. You'll see "Picked up where you left off".

    • It only works for the exact same file. If you edit the deck in PowerPoint, the fixer starts fresh.
    • It only works in the same browser on the same computer.
    • Saved work is removed after 30 days.
    • "Start over from the file" throws away your saved typing for that file.
    • If other people use the same computer login, open "Saved work" at the bottom of the slide list and choose "Delete saved work for this file" when you're finished.

    What this page doesn't check

    The fixer checks slide titles and alt text only. Use PowerPoint's Check Accessibility for the rest:

    • charts, tables, SmartArt and shapes filled with a picture (the fixer points these out)
    • text contrast
    • reading order

    If something goes wrong

    "Couldn't open that file"
    The fixer opens .pptx files up to 250 MB. If yours is larger, compress the pictures in PowerPoint (Picture Format, then Compress Pictures) and save again. If the file is damaged, open it in PowerPoint and save a new copy.
    "No preview for this picture"
    The picture is in a format the browser can't show, such as SVG, or it's too large to preview. You can still describe it. Open the deck in PowerPoint to see which picture it is.
    "This browser isn't saving your work"
    The browser is blocking storage, usually because of a privacy setting. Your typing still works, but download the fixed copy before you close the tab.
    The download didn't appear
    Check your browser's Downloads folder for a file ending in "(fixed).pptx".
